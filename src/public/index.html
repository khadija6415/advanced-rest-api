Features

🔐 JWT Authentication

Register and login with bcrypt hashed passwords and signed tokens.

🛡️ Role-based access

Public reads, login required for writes, admin only deletes.

✅ Validation

Every input is validated and returns clear 400 error details.

🔎 Search and pagination

Filter, sort and paginate categories and courses.

🧱 Modular MVC

Routes, controllers, models, validators and middlewares kept separate.

⚙️ Secure by default

Helmet headers, CORS, rate limiting and one central error handler.

Endpoints

Tap an endpoint to see its details. Protected routes need the header Authorization: Bearer <token>.

Response format

Success

{
  "success": true,
  "message": "Category created successfully",
  "data": { "category": { "...": "..." } }
}

Error

{
  "success": false,
  "message": "Validation failed",
  "errors": [
    { "field": "email", "message": "Email is required" }
  ]
}
